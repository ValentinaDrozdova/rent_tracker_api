# Автоматический трекер арендных платежей (API)

Это FastAPI-приложение автоматизирует процесс отслеживания оплат за аренду гаражей. Оно предоставляет API-эндпоинт, который принимает файлы с данными по аренде и банковской выпиской, а в ответ отдает готовый отчет в формате Excel.

## Как работает

Приложение имеет один основной эндпоинт `/generate_report/`:

1.  Он принимает два xlsx-файла: с данными по аренде и банковской выпиской.
2.  Сопоставляет платежи по **уникальной сумме аренды**.
3.  Рассчитывает статус для каждого платежа (`получен`, `просрочен` и т.д.), учитывая 3-дневный льготный период.
4.  Формирует и отдает в качестве ответа готовый `.xlsx` файл.

## Установка и запуск через Docker

**Требования:**
* Установленный [Docker](https://www.docker.com/get-started).

**Шаги запуска:**

1.  Клонируйте репозиторий:
    ```bash
    git clone <URL репозитория>
    cd rent-tracker-project
    ```

2.  Соберите Docker-образ. Выполните команду в корневой папке проекта (где находится `Dockerfile`):
    ```bash
    docker build -t rent-tracker-api .
    ```

3.  Запустите контейнер из созданного образа:
    ```bash
    docker run -d -p 8000:80 --name rent-api rent-tracker-api
    ```

4.  Приложение будет доступно по адресу `http://localhost:8000`.

## Использование API

1.  Откройте в браузере документацию Swagger UI по адресу `http://localhost:8000/docs`.
2.  Найдите эндпоинт `POST /generate_report/`.
3.  Нажмите "Try it out" и загрузите два ваших xlsx-файла.
4.  Нажмите "Execute". В ответ вы получите `payment_status_report.xlsx` для скачивания.

## Автоматическая генерация отчетов (Cron)

Проект включает в себя скрипт `worker.py` для автоматической генерации отчетов и отправки их в Telegram по расписанию.

### Настройка

1.  **Создайте папку `data`** в корне проекта и положите в нее ваши файлы `arenda.xlsx` и `print 2.xlsx`.
2.  **Настройте Telegram.** В файле `worker.py` укажите ваши `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
